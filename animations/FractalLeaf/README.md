# Fractal Leaf

An upside-down recursive **binary tree** rendered as a leaf/frond: a deep-blue
trunk fading to light-blue twigs, topped off with a multi-coloured canopy
(green → gold → red → violet). The whole shape is generated by one function so
the branching **angle** is trivial to tune.

![reference](../../images/) <!-- inspired by a classic binary fractal tree -->

## The function

```python
from fractal_leaf import fractal_leaf

tree = fractal_leaf(
    angle_deg=25,        # ← the star parameter: branch turn angle
    depth=9,             # recursion depth (more branches / bushier)
    length_ratio=0.72,   # each child is 72% of its parent's length
    direction=DOWN,      # grows downward → hangs like a leaf
)
```

Any two trees of the **same depth** share the same structure, so they morph
smoothly into one another with `Transform` — that's what powers the angle sweep.

## The scene

`FractalLeaf` runs three phases:

1. **Construction** — the leaf grows one depth level at a time, then the
   colourful canopy blooms.
2. **The angle** — a small tree with the branching angle `θ` annotated.
3. **The sweep** — `θ` goes from **15° → 90°** in **5°** steps (and back),
   showing how wildly the final shape changes from the *same* trunk.

## Render

```bash
./render.sh              # full animation, 480p (fast), reuses the CNN venv
./render.sh -p           # ... and open it when done
./render.sh -q h -p      # 1080p
./render.sh LeafStill -s # a quick PNG still to eyeball the shape
```

`render.sh` reuses the manim `.venv` from the CNN series if it exists; otherwise
it bootstraps a local `.venv` from `requirements.txt`. Output lands in `media/`
(git-ignored).

## Tuning

The knobs live at the top of `fractal_leaf.py`: `ANGLE_HERO`, `DEPTH_HERO`,
`DEPTH_SWEEP`, `LENGTH_RATIO`, `TRUNK_BLUE` / `TIP_BLUE`, and `LEAF_PALETTE`.
